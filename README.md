# O-NET M.3 English — Teacher Edition

เว็บแอปฝึกภาษาอังกฤษสำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 3

## วิธีใช้งาน
1. เปิด `index.html` ในเว็บเบราว์เซอร์ หรือเผยแพร่ผ่าน GitHub Pages
2. เลือก Tutor Mode หรือ Exam Mode
3. เลือกหมวดข้อสอบและเวลาที่ต้องการ แล้วกดเริ่มทำแบบฝึกหัด

## วิธีเพิ่มข้อสอบ
ค้นหา `const QUESTIONS = [` ใน `index.html` แล้วเพิ่ม object ตามโครงสร้างนี้:

```js
{id:14,cat:"Grammar",q:"Your question",th:"คำแปลภาษาไทย",opts:["A","B","C","D"],ans:0,why:"Explanation",grammar:"Grammar tip"}
```
`ans` ใช้เลข 0–3 แทนตัวเลือก A–D

## หมายเหตุ
ข้อสอบตัวอย่าง 13 ข้อเป็นข้อสอบฝึกที่สร้างขึ้นใหม่ ไม่ใช่ข้อสอบ O-NET ทางการหรือข้อสอบย้อนหลังฉบับจริง

## ข้อจำกัดเวอร์ชันเริ่มต้น
ยังไม่มีระบบบัญชีนักเรียน/ครู ฐานข้อมูลออนไลน์ การบันทึกคะแนนข้ามอุปกรณ์ หรือการส่งออก Excel

## ชุดติวพร้อมสไลด์ (tutor/)
- เปิด `tutor/index.html` — สไลด์ติวแบบนักสืบ วิเคราะห์ข้อสอบจริง 2566–2568 ครบ 96 ข้อ (เฉลยตรวจกับ สทศ. แล้ว) และชุดเสมือนจริง 32 ข้อ
- ไม่มีข้อสอบ สทศ. อยู่ในไฟล์ ครูเลือกไฟล์ PDF ของตัวเองในเครื่องเพื่อให้โจทย์ขึ้นบนสไลด์
- `supabase/schema.sql` — โครงตารางสำหรับบันทึกคะแนนนักเรียน (ยังไม่ได้เชื่อมกับหน้าเว็บ)
